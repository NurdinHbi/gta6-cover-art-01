Vice City Nights turns your own photos and a caption into GTA 6-style multi-panel cover art with a Vice City sunset or neon grade, and exports it as a PNG in the common post sizes. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
python3 -m http.server --directory app 8000
```

Then open http://localhost:8000 — pick photos (or the bundled samples), write a caption, choose a layout and grade, crop each panel, and hit Export PNG. `node main.ts` writes the dossier (set `MAKEFUN_OUTPUT_DIR` to choose where).
